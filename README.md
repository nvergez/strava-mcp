# strava-mcp

A [Model Context Protocol](https://modelcontextprotocol.io/) server for the [Strava API](https://developers.strava.com/).

## Prerequisites

- [Node.js](https://nodejs.org/) >= 24
- [pnpm](https://pnpm.io/)

## Setup

```bash
pnpm install
```

## Development

```bash
# Build
pnpm build

# Watch mode
pnpm dev

# Run tests
pnpm test

# Lint
pnpm lint

# Format
pnpm format
```
